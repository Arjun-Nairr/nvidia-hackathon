## Standards axis

Server accepts client request IDs. A synthetic configured secret used as request_id is queued verbatim while the same value in inputs is redacted. Violates HANDOUT's no-secret rule and the task's redaction requirement. Apply consistent protection at emit and worker acceptance; preserve safe deterministic correlation where an ID needs transformation.
2. **[P2] Preview slicing precedes secret removal.** app/server.py:114 and :152 take 300 characters before sanitization.
